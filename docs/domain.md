# Domain

## Apartment

An apartment represents a property that a user wants to evaluate during their housing search.

## Attributes

| Field | Description | Required |
|---|---|---|
| title | Apartment name | Yes |
| price | Monthly price | Yes |
| location | Apartment location | Yes |
| area | Size in square meters | No |
| bedrooms | Number of bedrooms | No |
| bathrooms | Number of bathrooms | No |
| url | Original listing URL | No |
| notes | User observations | No |

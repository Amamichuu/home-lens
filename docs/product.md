# Product

## Overview

HomeLens is a web application that helps people organize, compare and evaluate apartment listings.

The goal is to replace spreadsheets and dozens of browser tabs with a simple workspace for apartment hunting.

---

## Target Audience

People looking to rent or buy an apartment.

Initially focused on individuals comparing multiple listings.

---

## Problem

Searching for an apartment is frustrating.

People usually:

- Open many browser tabs
- Forget interesting listings
- Compare apartments manually
- Lose important information
- End up creating spreadsheets

---

## Solution

HomeLens allows users to:

- Create a comparison
- Save apartment listings
- Compare apartments side by side
- Keep personal notes
- Make better housing decisions

---

## MVP

- Create a comparison
- Add apartments manually
- Compare apartments
- Save notes

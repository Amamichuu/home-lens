# HomeLens

HomeLens is a web application that helps people organize and compare apartment listings without relying on spreadsheets.

Instead of juggling dozens of browser tabs and manually comparing prices, users can save listings, compare properties side by side, and make more confident housing decisions.

## MVP

- Create apartment comparisons
- Add apartments manually
- Compare selected apartments
- Save personal notes

## Tech Stack

### Backend

- Python
- FastAPI
- PostgreSQL

### Frontend

- Svelte (planned)
